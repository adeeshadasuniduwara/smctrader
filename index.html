Roadmap — not built yet

These need a paid data API, a backend, or are large enough to be their own build session. Skipped this round so the rest could be solid rather than everything being half-working:

  • Wyckoff phase detection (subjective pattern, low automatic-detection value)
  • Crypto news feed, economic calendar, DXY overlay, exchange net-flow — all need a paid/keyed data API
  • Whale trade alerts — needs a persistent WebSocket stream, not a REST poll
  • Full order book depth heatmap (built: simple bid/ask imbalance %)
  • Inducement / Turtle Soup / Judas Swing / Power of Three / PD Array ranking — refinements on top of today's liquidity-sweep logic
  • OKX as a second alternate exchange (Bybit is now supported)
